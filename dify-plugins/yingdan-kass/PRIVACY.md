## Privacy

本插件只处理执行赢单客户 KASS Tool 所必需的数据。

- Dify Provider 保存 `api_base_url`、`user_id` 与 `access_token`；插件不会把 Access Token 返回给模型或写入业务日志。
- 客户资料、跟进记录和上传文件只发送到管理员配置的赢单 API，不发送到其它第三方服务。
- 上传文件会在单次 Tool 调用期间读入内存，然后发送到赢单文件接口；插件不自行长期保存文件内容。
- `prepare_delete` 会在 Dify Plugin Storage 中保存一次性确认令牌、资源类型、资源 ID、展示名称和过期时间，默认五分钟后失效；不会保存客户完整档案。
- 业务数据的最终保存、保留和删除规则由赢单服务与部署方负责。

使用本插件前，部署方应确认其有权访问和修改所配置赢单账号下的数据，并限制 Dify 工作区成员和 Agent 对写入、上传与删除 Tool 的使用权限。
