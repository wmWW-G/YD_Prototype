# Privacy Policy / 隐私说明

This plugin sends the prompt, selected generation parameters, and optional reference images either to Google's official Gemini API or to OpenRouter's Image API, depending on the selected model. The configured Gemini API key is sent only to Google, and the configured OpenRouter API key is sent only to OpenRouter.

The plugin does not operate an independent backend, does not sell data, and does not intentionally persist prompts, reference images, generated images, or API keys. Dify, Google, OpenRouter, and the model provider behind OpenRouter may process or retain data according to their own deployment settings, terms, and privacy policies.

本插件会根据所选模型，把提示词、所选生成参数和可选参考图片发送到 Google 官方 Gemini API 或 OpenRouter Image API，以完成图片生成或编辑。Gemini API Key 仅发送给 Google，OpenRouter API Key 仅发送给 OpenRouter。

插件不运行独立中转后端，不出售数据，也不会主动持久化提示词、参考图片、生成图片或 API Key。Dify、Google、OpenRouter 及 OpenRouter 背后的模型供应商仍可能依据各自的部署配置、服务条款和隐私政策处理或保留数据。
